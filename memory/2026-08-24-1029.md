**Per modificare config OpenClaw:**

3. Se serve restart, OpenClaw te lo dice e riavvia automaticamente

**Esempio:**
```bash
# Vedere schema di un campo specifico
gateway action=config.schema.lookup path="agents.main.model"

# Modificare un campo
gateway action=config.patch raw='{"agents":{"main":{"model":"sonnet"}}}'
```
