## Come funziona

Script bash che chiama `/v1/audio/transcriptions` di OpenAI. Supporta file audio fino a 25 MB.

## Uso base

```bash
/tmp/openclaw/openclaw-claude-skills-7vfpbw/openclaw-skills/skills/openai-whisper-api/scripts/transcribe.sh /path/to/audio.m4a
```

Default: modello `gpt-4o-transcribe`, output in `<input>.txt`

## Opzioni utili

```bash
# Modello specifico
--model gpt-4o-transcribe          # qualità alta
--model gpt-4o-mini-transcribe     # più veloce
--model gpt-4o-transcribe-diarize  # con speaker labels
--model whisper-1                  # classico

# Output
--out /path/output.txt
--json                             # formato JSON strutturato

# Contesto
--language it                      # forza italiano
--prompt "Nomi speaker: Marco, Luca"  # aiuta il riconoscimento
```

## Formati supportati
`mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `wav`, `webm`

## Configurazione API key

Serve `OPENAI_API_KEY` in ambiente, oppure in `~/.openclaw/openclaw.json`:

```json
{
  "skills": {
    "openai-whisper-api": {
      "apiKey": "***"
    }
  }
}
```

Opzionale: `OPENAI_BASE_URL` per proxy o gateway locale.
