## Il Pattern Ideale: Lazy Loading

Invece di caricare tutto:
```
Tool: message
Description: 3.500 token di schema JSON completo con 100+ parametri
```

Carica solo:
```
Tool: message (deferred)
Description: "Send/delete/manage channel messages" (~20 token)
```

Poi **quando sto per usare il tool**, chiamo `ToolSearch` che carica lo schema completo.

## OpenClaw Già Lo Supporta! 

Guarda la lista "deferred tools" che ricevo:
```
CronDelete, CronList, TodoWrite, WebSearch, 
mcp__colzani-mcp__* (tutti i tool Colzani)
```

Questi tool **esistono** ma pesano ~10-20 token ciascuno (solo nome), non ~500-2000.

Il problema è che **la maggioranza dei tool è "always loaded"** invece di deferred:
- ✅ Deferred: ~30 tool Colzani (lightweight)
- ❌ Always loaded: message, browser, cron, google_meet, etc. (heavyweight)
