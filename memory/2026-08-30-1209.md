`openclaw mcp serve` **espone** le conversazioni OpenClaw ad altri client MCP (Claude Desktop, Claude Code, Cursor).

- Conversazioni dei canali (Telegram, Discord, ecc.)

- Tool per inviare messaggi (`messages_send`)
- Eventi live (`events_poll`, `events_wait`)
- History/transcript
- Tool di approvazione

- Vuoi controllare le chat OpenClaw da Claude Desktop/Code
- Vuoi un bridge MCP unificato per tutti i canali invece di bridge separati

**Esempio:**
```bash
openclaw mcp serve
```
